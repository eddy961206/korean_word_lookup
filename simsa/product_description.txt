Korean Word Lookup: Translate & Save Words

Meet a new Korean word. Understand it without losing your place.

Hover over Korean text for an English or Vietnamese translation right on the page. Pin a result while you read, copy it when you need it, or save the source word to your own vocabulary notebook.

Read your way
- Choose English or Vietnamese as your result language, independently of the interface language.
- Look up words by hovering, or use Alt / Option + hover for more deliberate control.
- Turn on selection translation for Korean phrases and sentences up to 500 characters. It is off by default and uses Google.
- Pin, unpin, or close the result panel. If a word form has no result, edit it and try again.
- Adjust hover delay, compact mode, and the number of dictionary definitions.

Build your own word notebook
- Save words you choose, then write your own meanings, examples, and notes.
- Search and edit entries. Undo a deletion.
- Export CSV or TSV for use in other study tools, or back up and restore with JSON. Import adds new words and keeps existing entries unchanged.
- The notebook is local to this Chrome profile. There is no account or cloud notebook sync. Provider translations are not automatically saved or prefilled.

Choose a lookup source
Google Translate works without entering an API key. For Korean Basic Dictionary entries, use your own KRDICT key. The dictionary key stays only in memory for the current Chrome session; enter it again after a browser restart or extension reload/update. Optional source fallback can try the other provider when a word lookup has no usable result.

Control what is sent
Lookup text goes to the relevant translation or dictionary provider. Pause a site or turn translation off before reading text you do not want sent. Input/password fields, editable regions, and selections crossing editable content are skipped. Other page text may still be private. Paused hostnames are stored only locally.

This version sends no remote product analytics. Ordinary reading settings can sync through Chrome; notebook entries and local feature counters do not. The notebook is not encrypted. Export a backup before uninstalling, and keep exported files private. See the privacy policy for data handling and retention details.

Getting started
Install, refresh a regular Korean web page, and hover over a word. Open the extension popup to choose a result language, change the lookup trigger, enable sentence selection, or open your notebook.

The interface supports English, Korean, and Vietnamese. Online lookups require internet access and provider availability. Chrome restricts extensions on some pages. This is an independent extension, not a full-page translator, automatic grammar analyzer, or direct Anki integration. Dictionary text is provided by the National Institute of Korean Language under CC BY-SA 2.0 Korea.
