Korean Word Lookup - Korean to English Translator & Dictionary

Read Korean articles, posts, and study pages with English help beside the text. Hover over a Korean word to look it up, or enable selection translation and select a sentence to understand it without opening another tab.

Start with Google Translate
- No API key is needed for Google translations.
- After installing or updating, refresh a web page you already had open, then hover over a Korean word.
- To translate sentences, turn on selection translation in the extension popup. Each selection can contain up to 500 characters.

Look up words in more detail
- Add your own KRDICT API key in the popup to use the Korean Basic Dictionary's detailed definitions.
- Choose Google Translate or KRDICT, and adjust the number of definitions and whether Korean definitions appear.
- Auto-Fallback can try the other source if a lookup fails or returns no result. KRDICT still requires your API key.

Adjust it to your reading
- Toggle translation on or off, change the hover delay, or use a compact tooltip.
- Windows/Linux/ChromeOS shortcuts: Alt+T to toggle translation, Alt+G for Google, Alt+K for KRDICT, and Alt+S for selection translation.
- On Mac, use Option+Shift with the same letters.

Where it works
- Designed for Korean text on ordinary web pages. Chrome internal pages, the Chrome Web Store, and some PDF viewers do not support it.
- Online translation and dictionary lookups need an internet connection.

Privacy
- The text you look up is sent to Google Translate or KRDICT as needed to provide translations or definitions.
- Settings are stored in Chrome storage.
- External product analytics are off by default and require opt-in. Local usage counters stay in Chrome storage. Raw hovered or selected text is never sent to product analytics.
