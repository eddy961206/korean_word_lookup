Korean Word Lookup - 한국어 단어와 문장을 영어로

한국어 기사, 게시글, 학습 자료를 읽으면서 영어 뜻을 바로 확인해. 단어에 마우스를 올려 뜻을 찾고, 선택 번역을 켠 뒤 문장을 드래그하면 새 탭을 열지 않고 영어 번역을 볼 수 있어.

Google Translate로 바로 시작해
- Google 번역에는 API 키가 필요하지 않아.
- 설치하거나 업데이트한 뒤 이미 열려 있던 웹페이지를 새로고침하고 한국어 단어에 마우스를 올려봐.
- 문장을 번역하려면 확장 프로그램 팝업에서 선택 번역을 켜줘. 한 번에 최대 500자까지 선택할 수 있어.

자세한 사전 뜻이 필요할 때
- 팝업에 개인 KRDICT API 키를 입력하면 한국어기초사전의 자세한 뜻풀이를 볼 수 있어.
- Google Translate와 KRDICT 중 조회 소스를 고르고, 뜻풀이 개수와 한국어 정의 표시 여부를 조절해.
- 자동 대체 조회는 조회가 실패하거나 결과가 없을 때 다른 소스를 시도해. KRDICT를 이용하려면 이때도 개인 API 키가 필요해.

읽는 방식에 맞춰 조절해
- 번역 켜기/끄기, 호버 지연 시간, 컴팩트 툴팁을 설정할 수 있어.
- Windows/Linux/ChromeOS: Alt+T는 번역 켜기/끄기, Alt+G는 Google, Alt+K는 KRDICT, Alt+S는 선택 번역이야.
- Mac에서는 같은 글자와 Option+Shift를 함께 눌러줘.

사용 범위
- 일반 웹페이지의 한국어 텍스트를 위한 도구야. Chrome 내부 페이지, Chrome 웹스토어, 일부 PDF 뷰어에서는 동작하지 않아.
- 온라인 번역과 사전 조회에는 인터넷 연결이 필요해.

개인정보 안내
- 조회한 텍스트는 번역이나 뜻풀이를 가져오는 데 필요한 경우 Google Translate 또는 KRDICT로 전송돼.
- 설정값은 Chrome 저장소에 저장돼.
- 외부 제품 분석 전송은 기본적으로 꺼져 있고 직접 동의해야 활성화돼. 로컬 사용 횟수는 Chrome 저장소에 남아. 제품 분석에는 호버하거나 선택한 원문 텍스트를 보내지 않아.
