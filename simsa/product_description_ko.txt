한국어 번역 · 내 단어장 | Korean Word Lookup

모르는 한국어 단어가 나와도, 읽던 흐름을 이어 가세요.

한국어 텍스트에 마우스를 올려 영어 또는 베트남어 뜻을 바로 확인하세요. 결과창을 고정해 비교하거나 복사하고, 기억하고 싶은 원문 단어는 내 단어장에 저장할 수 있습니다.

내 방식대로 읽기
- 화면 언어와 별개로 번역 결과 언어를 영어·베트남어 중 선택합니다.
- 마우스를 올려 조회하거나, Alt / Option을 누른 채 마우스를 올릴 때만 조회하도록 바꿀 수 있습니다.
- 선택 번역을 켜면 최대 500자의 구절·문장을 Google로 번역합니다. 기본 설정은 꺼짐입니다.
- 결과창 고정·해제·닫기, 복사, 단어 저장을 지원합니다. 결과가 없는 단어는 직접 고쳐 다시 조회할 수 있습니다.
- 툴팁 지연 시간, 간단히 보기, 사전 뜻 개수를 조절할 수 있습니다.

나만의 단어장 만들기
- 내가 고른 단어를 저장하고, 직접 쓴 풀이·예문·메모를 더하세요.
- 검색·수정·삭제 후 실행 취소를 지원합니다.
- CSV·TSV로 내보내 다른 학습 도구에서 활용하거나 JSON으로 백업·복원할 수 있습니다. 가져오기는 기존 항목을 덮어쓰지 않고 새 단어만 추가합니다.
- 단어장은 현재 Chrome 프로필에만 저장됩니다. 계정이나 클라우드 단어장 동기화는 없습니다. 제공자의 번역문은 자동 저장하거나 미리 채우지 않습니다.

조회 제공자 선택
Google 번역은 API 키를 입력하지 않고 사용할 수 있습니다. 국립국어원 한국어기초사전(KRDICT)을 이용하려면 본인의 API 키가 필요합니다. 키는 현재 Chrome 세션의 메모리에만 보관되며, 브라우저 재시작이나 확장 프로그램 재로드·업데이트 후 다시 입력해야 합니다. 자동 대체 조회를 켜면 단어 결과가 없을 때 다른 제공자로 다시 조회할 수 있습니다.

전송 범위 직접 조절
조회한 단어나 선택한 글은 해당 번역·사전 제공자에게 전송됩니다. 보내고 싶지 않은 글을 읽기 전에는 해당 사이트에서 일시중지하거나 번역을 꺼 주세요. 입력란·비밀번호·편집 영역과 그 영역에 걸친 선택은 조회하지 않지만, 다른 페이지 텍스트에도 사적인 내용이 있을 수 있습니다. 일시중지한 도메인은 로컬에만 저장합니다.

이 버전은 외부 제품 분석 정보를 전송하지 않습니다. 일반 읽기 설정은 Chrome을 통해 동기화될 수 있지만 단어장과 로컬 사용 횟수는 동기화하지 않습니다. 단어장은 암호화되지 않으므로 삭제 전 백업하고 내보낸 파일을 안전하게 보관하세요. 자세한 처리·보관 기간은 개인정보처리방침을 확인하세요.

시작하기
설치 후 일반 한국어 웹페이지를 새로고침하고 단어에 마우스를 올려 보세요. 팝업에서 결과 언어·조회 방식을 바꾸고 선택 번역을 켜거나 단어장을 열 수 있습니다.

화면 언어는 한국어·영어·베트남어를 지원합니다. 온라인 조회에는 인터넷과 제공자 서비스가 필요하며, Chrome이 확장 실행을 제한하는 페이지에서는 동작하지 않습니다. 전체 페이지 번역, 자동 문법 분석, Anki 직접 연동 기능은 아닙니다. 독립적으로 개발한 확장 프로그램이며, 사전 텍스트는 국립국어원 한국어기초사전의 CC BY-SA 2.0 대한민국 조건을 따릅니다.
