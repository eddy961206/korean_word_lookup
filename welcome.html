Welcome to Korean Word Lookup!

Thank you for installing Korean Word Lookup. Here's how to get started.

⚡ Try your first translation

  1. Open the extension icon, turn on word translation, and select Google Translate.
  2. Open the Korean Wikipedia test page with the button below.
  3. Hover over a Korean word on that page to see its English meaning.

For sentences, enable selection translation in the popup, then highlight Korean text.

Google Translate works without an API key. Korean Dictionary (KRDICT) requires your own key.

🔍 Main Features

  • Hover over Korean words to see their English translations or definitions
  • Choose between Google Translate and Korean Dictionary
  • Auto-Fallback: Automatically switches to Google Translate if dictionary lookup fails
  • Google Translate - Quick word-to-word translations
  • Korean Dictionary - Detailed word definitions
  • Use keyboard shortcuts for quick access to features
  • Customize hover delay, tooltip size, and definition depth from the popup
  • Select Korean sentences to translate them instantly

⌨️ Keyboard Shortcuts

  • Alt+T - Toggle translation on/off
  • Alt+G - Switch to Google Translate
  • Alt+K - Switch to Korean Dictionary
  • Alt+S - Toggle selection translation

🚀 Getting Started

  1. Click the extension icon in your browser toolbar
  2. Pin the extension to see whether extension is enabled
  3. Make sure translation is enabled (toggle switch is on)
  4. Choose your preferred translation source
  5. Hover over any Korean text to see its translation!
